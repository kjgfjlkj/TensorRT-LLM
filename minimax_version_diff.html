5. 部署配置差异

M2.5 在 AMD GPU 上引入了专属的 AITER 注意力后端，性能更优

M2.1 — NVIDIA 标准部署（4 GPU）

python -m sglang.launch_server \
  --model-path MiniMaxAI/MiniMax-M2.1 \
  --tp-size 4 \
  --tool-call-parser minimax-m2 \
  --reasoning-parser minimax-append-think \
  --host 0.0.0.0 \
  --trust-remote-code \
  --port 8000 \
  --mem-fraction-static 0.85

M2.5 — AMD GPU 推荐部署（8 GPU）

SGLANG_USE_AITER=1 python -m sglang.launch_server \
  --model-path MiniMaxAI/MiniMax-M2.5 \
  --tp-size 8 \
  --ep-size 8 \
  --attention-backend aiter # M2.5 新增
  --tool-call-parser minimax-m2 \
  --reasoning-parser minimax-append-think \
  --host 0.0.0.0 \
  --trust-remote-code \
  --port 8000 \
  --mem-fraction-static 0.85

部署关键差异总结

AMD AITER 后端
M2.5 新增 --attention-backend aiter 与 SGLANG_USE_AITER=1，在 MI 系列 GPU 上获得更高吞吐
NVIDIA 无变化
NVIDIA GPU 上两个版本部署命令完全相同，只需切换 --model-path
多线程加载
AMD CI 测试中 M2.5 使用 enable_multithread_load: true，加速模型加载
Watchdog 超时
M2.5 AMD 测试设置 --watchdog-timeout 1200，适配更大模型的加载时间

升级建议

推荐使用 M2.5：SGLang 官方已将 nightly 测试从 M2 替换为 M2.5，表明 M2.5 是当前生产推荐版本。

AMD GPU 用户：M2.5 + AITER 后端组合可获得最高性能，AMD MI325X 上 GSM8K 准确率门槛高达 93%。

迁移成本极低：两个版本使用同一套 SGLang 代码（minimax_m2.py），NVIDIA 上仅需修改 --model-path 即可完成升级。
