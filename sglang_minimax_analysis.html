6. TBO：Two Batch Overlap 批次重叠优化

MiniMax M2 对 TBO 有完整支持，通过将批次 N 的 MoE all-to-all 与批次 N+1 的注意力计算重叠，大幅提升 GPU 利用率。

TBO 时间线：MoE 8 步操作

TBO 使 Batch N+1 的 gate/select/dispatch 与 Batch N 的 expert 计算并行执行，隐藏 all-to-all 通信延迟。MiniMax M2 是 SGLang 中对 TBO 支持最完整的模型之一。

7. 函数调用：XML 流式格式

MiniMax M2 使用独特的 XML 标签格式（而非 JSON）进行函数调用，专为 Agent 任务和流式输出设计。

MiniMax XML 格式 vs 标准 JSON


<minimax:tool_call>
<invoke name="search_web">
  <parameter name="query">SGLang MiniMax</parameter>
  <parameter name="max_results">10</parameter>
</invoke>
</minimax:tool_call>


{
  "name": "search_web",
  "arguments": {
    "query": "SGLang MiniMax",
    "max_results": 10
  }
}

XML 格式的优势 Agent 优化

流式解析 (Streaming)
XML 标签可以增量解析，参数 token 一出现就可以识别，无需等待完整 JSON 结构
参数增量构建
MinimaxM2Detector 实时追踪 XML 解析状态，边生成边构建参数对象，支持复杂嵌套类型 (anyOf/oneOf/allOf)
部分执行支持
Agent 任务中可以在函数调用生成完成前就启动准备工作，降低端到端延迟
