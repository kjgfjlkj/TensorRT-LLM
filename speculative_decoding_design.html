1. 投机解码概述

利用轻量 draft 模型预先生成 K 个候选 token，再由 target 模型一次前向并行验证，不改变输出分布的同时提升吞吐量。

基本循环
Draft 模型
生成 K 候选 token
→
Target 模型
一次前向验证 K+1 位置
→
接受/拒绝
连续前缀接受
→
输出
≥1 个新 token

Eagle TRT

独立 Eagle 网络（LLaMA 结构），通过 TRT Plugin 驱动 token 树。支持静态树（Eagle-1）和动态树（Eagle-2）。

tensorrt_llm/models/eagle/model.py

Eagle3 Torch

从 target 的 3 个深度层捕获隐状态拼接后送入 Eagle draft 网络。支持 OneModel 和 TwoModel+CDL。

tensorrt_llm/_torch/speculative/eagle3.py

MTP Torch

N 个 MTP 模块附加于 target，共享 embed+lm_head，无独立 draft 引擎，每模块预测下一位置 token。

tensorrt_llm/_torch/speculative/mtp.py

3.3 三个核心 Plugin 详解

Plugin 1 — EagleSampleAndAcceptDraftTokensPlugin

cpp/tensorrt_llm/plugins/eaglePlugin/eagleSampleAndAcceptDraftTokensPlugin.cpp

对 target logits 采样并验证 draft tokens。支持 greedy / multinomial / typical acceptance 三种模式。

关键输入形状说明
lm_logits[num_tokens, vocab]Target 模型所有位置的 logits
draft_tokens[batch, max_draft]上一轮 Eagle 生成的候选 tokens
draft_lens[batch]context=0，generation=K
tree_params.paths[batch, max_decode, max_path]token 树路径矩阵
greedy_sampling[1]是否 top-1 greedy
use_dynamic_tree[1]Eagle-1 静态 / Eagle-2 动态
关键输出说明
accepted_tokens被接受的 token ids
num_accepted_tokens每 request 实际接受数（≥1）
accepted_paths被接受路径在树中的索引
next_draft_tokens/lens/paths为下一轮分配的空 buffer
hidden_size_batch_level_starts为 Plugin2 提供每 request 隐状态起始偏移

Plugin 2 — EaglePrepareDrafterInputsPlugin

cpp/tensorrt_llm/plugins/eaglePlugin/eaglePrepareDrafterInputsPlugin.cpp

从 target hidden states 中 gather 接受路径上各节点的隐状态，并计算 position ids，生成 EagleNet 第一步输入。

  • 沿 accepted_paths 展开树路径，取对应深度 hidden states
  • 计算每个 draft 位置的 position id（根节点 position + 路径深度）
  • 输出扁平化 eagle_input_ids / position_ids / hidden_states

Plugin 3 — EagleDecodeDraftTokensPlugin（每 Eagle 层一次）

cpp/tensorrt_llm/plugins/eaglePlugin/eagleDecodeDraftTokensPlugin.cpp

在每个 Eagle 层输出 logits 后进行 top-K/multinomial 采样，维护 token 树动态扩展。

参数说明
layer_idx / num_eagle_layers当前/总 Eagle 层数
input_prev_scores上一层各节点得分
input_current_expand_indices本层要扩展的节点（Eagle-2 动态选择）
input_all_layers_scores/tokens/predecessorsEagle-2 跨层全局得分记录（beam 选优）

4. Eagle3 — Torch 后端

4.1 核心思想：多层隐状态捕获

从 target 模型的 3个不同深度层（layer 1、layer N/2-1、layer N-4）捕获隐状态，拼接为 3H 维向量，经 eagle3_fc 压缩为 H 维作为 Eagle draft 网络的条件输入。

Target 模型（N=32）隐状态捕获点
Embed
→
Layer 1
capture H1
→
Layer 2..14
→
Layer 15
capture H15
→
Layer 16..27
→
Layer 28
capture H28
→
Layer 29..32
→
LM Head
concat[H1; H15; H28] → [token, 3H] → eagle3_fc → [token, H] → Eagle Draft Network
# SpecMetadata.maybe_capture_hidden_states() 在 target 每层后被调用
def maybe_capture_hidden_states(self, layer_id, hidden_states, residual=None):
    for i, captured_layer_id in enumerate(self.layers_to_capture):  # (1, 15, 28)
        if captured_layer_id == layer_id:
            to_save = hidden_states + residual if residual is not None else hidden_states
            # 写入第 i 段：eagle3_buffer[:, i*H:(i+1)*H]
            eagle3_hidden[:, i*H:(i+1)*H].index_copy_(0, write_indices, to_save)
            break

# 默认捕获层：layers_to_capture = (1, N//2-1, N-4)  N=32 时为 (1, 15, 28)
# MTP_EAGLE / 单层模型：layers_to_capture = (-1,)  仅最后一层

4.2 Eagle3 变体模式

EAGLE3 TwoModel Torch

两个独立引擎：target + draft 分开。

  • Target 前向捕获3层 hidden → 写入 Eagle3ResourceManager
  • Draft 引擎（独立 Eagle 网络）从缓冲区读取
  • LinearDraftingLoopWrapper（CDL）封装自回归循环，可 CUDA Graph 捕获
  • Draft 第一步需 KV cache recompute
_torch/speculative/drafting_loops.py

EAGLE3_ONE_MODEL Torch

共享单引擎：draft 层内嵌于 target 模型。

  • 隐状态写入 Eagle3OneModelSpecMetadata.hidden_states
  • Target 前向完成后，Eagle3OneModelWorker 驱动 draft 层自回归
  • Draft 层权重从独立 checkpoint 加载
  • KV cache 可选分离（use_separate_draft_kv_cache）
_torch/speculative/eagle3.py — Eagle3OneModelWorker

索引机制： 每个 request 在 hidden_states 中有预分配连续块（start_idx 起，大小 = max(seq_len, max_total_draft_tokens+1)）。 通过 write_indices（target 写）和 read_indices（draft 读）零拷贝共享。 接受树路径后，read_indices 按 accepted_path gather 对应节点隐状态。

Generation Phase 1 — 接受 F G 拒绝 H（接受2个 draft）

# Target 输入: E F G H  (last_accepted + 3 drafts)
target_logits → argmax → [F, G, X, Y]

# 验证：
# draft[0]=F == target[0]=F  ✓
# draft[1]=G == target[1]=G  ✓
# draft[2]=H != target[2]=X  ✗  停止
# num_accepted = 2+1 = 3（2个draft + 1个golden X）

# update_mtp_hidden_states: k=3
# past_tokens[slot] = input_ids[0:3] = [E, F, G]
# past_hidden[slot] = hidden[0:3]    = [HE, HF, HG]

# MTP Module 1: tokens=[F,G,X] + hidden=[HE,HF,HG] → draft N
# MTP Module 2: tokens=[G,X,N] + hidden=[HF,HG,hX] → draft O
# MTP Module 3: tokens=[X,N,O] + hidden=[HG,hX,hN] → draft P
# next_draft_tokens = [N, O, P]

Relaxed Acceptance（DeepSeek-R1 思考模式）

# 标准接受：draft[i] == argmax(target_logits[i])
# 宽松接受：draft[i] ∈ top-K(target_logits[i])
#           且 P(draft[i]) >= delta × P(top1)
# delta 动态调整：接受率高 → 增大 delta（更严格）
#                接受率低 → 减小 delta（更宽松）
# topk_kernel 用 @torch.compile 加速
