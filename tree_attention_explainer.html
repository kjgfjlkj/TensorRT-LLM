整体架构概览
Tree Attention = Radix Tree KV Cache + 分块 Attention 计算
Tree Attention 的核心思想： 多个请求可能共享相同的前缀 token（如系统提示词 system prompt）。SGLang 用一棵 Radix Tree 索引所有已计算过的 KV Cache，新请求只需计算 未命中 的新 token，大幅减少重复计算。

前缀共享原理
理解 extend_prefix_lens 与 extend_seq_lens 如何分割 attention 计算
关键洞察： Extend 阶段的 query token 需要 attend to 两部分 KV — (1) 已缓存的 prefix KV (paged) 和 (2) 当前批次新增的 extend KV (ragged)。FlashInfer 用两个独立 wrapper 分别计算，再通过 log-sum-exp 技巧无损合并。
树操作详解
match_prefix / insert / split_node 三大核心操作

match_prefix 流程

给定新请求的 token 序列，在 Radix Tree 中找到最长公共前缀，返回对应的 KV cache 索引。

def match_prefix(self, params) -> MatchResult:
    key = params.key
    value = []
    last_node = self.root_node

    while len(key) > 0:
        # 从 key 首位查找子节点
        child_key = self.get_child_key_fn(key)
        if child_key not in node.children:
            break

        child = node.children[child_key]
        # 计算当前子节点与 key 的公共前缀长度
        prefix_len = self.key_match_fn(child.key, key)

        if prefix_len < len(child.key):
            # 部分匹配：需要分裂节点
            new_node = self._split_node(child.key, child, prefix_len)
            value.append(new_node.value)
            last_node = new_node
            break
        else:
            # 完全匹配：继续向下遍历
            value.append(child.value)
            last_node = child
            key = key[prefix_len:]  # 消耗已匹配部分
            node = child

    return MatchResult(
        device_indices=torch.cat(value) if value else empty,
        last_device_node=last_node,
    )

insert 流程

请求完成后，将新计算的 KV cache 插入 Radix Tree 以供后续请求复用。

def insert(self, params: InsertParams) -> InsertResult:
    key = params.key    # 完整 token 序列
    value = params.value # 对应 KV cache 索引

    prefix_len = self._insert_helper(
        self.root_node, key, value, params.priority
    )
    return InsertResult(prefix_len=prefix_len)

def _insert_helper(self, node, key, value, priority):
    total_prefix = 0

    while len(key) > 0:
        child_key = self.get_child_key_fn(key)

        if child_key not in node.children:
            break   # 找到插入位置

        child = node.children[child_key]
        prefix_len = self.key_match_fn(child.key, key)
        total_prefix += prefix_len

        if prefix_len == len(child.key):
            # 完全匹配，继续深入
            key = key[prefix_len:]
            value = value[prefix_len:]
            node = child
        else:
            # 部分匹配，先分裂再插入
            new_node = self._split_node(child.key, child, prefix_len)
            node = new_node
            key = key[prefix_len:]
            value = value[prefix_len:]
            break

    # 剩余 key 创建新节点
    if len(key) > 0:
        new_node = TreeNode(priority=priority)
        new_node.parent = node
        new_node.key = key
        new_node.value = value.clone()
        node.children[child_key] = new_node
        self.evictable_size_ += len(key)

    return total_prefix  # 已存在的前缀长度

_split_node 节点分裂

当查询/插入的 key 只与现有节点部分匹配时，需要分裂节点以精确对齐边界。

def _split_node(self, key, child, split_len):
    """
    Before: parent -> [1,2,3,4,5] (child)
    split_len=3
    After:  parent -> [1,2,3] (new) -> [4,5] (child)
    """
    # 创建新的中间节点
    new_node = TreeNode(priority=child.priority)
    new_node.children = {
        self.get_child_key_fn(key[split_len:]): child
    }
    new_node.parent = child.parent
    new_node.key = child.key[:split_len]
    new_node.value = child.value[:split_len].clone()

    # 更新 child 节点 (缩短 key)
    child.parent = new_node
    child.key = child.key[split_len:]
    child.value = child.value[split_len:].clone()

    # 更新 parent 的 children 指针
    new_node.parent.children[
        self.get_child_key_fn(key)
    ] = new_node

    return new_node  # 返回新的公共前缀节点

驱逐与内存管理
lock_ref 引用计数 + 多种驱逐策略，确保 KV Cache 被高效复用
inc_lock_ref / dec_lock_ref
def inc_lock_ref(self, node: TreeNode):
    while node != self.root_node:
        if node.lock_ref == 0:
            # evictable → protected
            self.evictable_size_ -= len(node.key)
            self.protected_size_ += len(node.key)
        node.lock_ref += 1
        node = node.parent  # 向上锁定整条路径

def dec_lock_ref(self, node: TreeNode):
    while node != self.root_node:
        node.lock_ref -= 1
        if node.lock_ref == 0:
            # protected → evictable
            self.evictable_size_ += len(node.key)
            self.protected_size_ -= len(node.key)
        node = node.parent
evict — LRU 驱逐核心
def evict(self, params: EvictParams):
    # 收集所有可驱逐叶节点
    leaves = list(self.evictable_leaves)
    heap = [(strategy.get_priority(n), n)
             for n in leaves]
    heapq.heapify(heap)

    num_evicted = 0
    while num_evicted < params.num_tokens:
        _, x = heapq.heappop(heap)
        # 释放 GPU KV 内存
        self.token_to_kv_pool_allocator.free(x.value)
        num_evicted += len(x.value)
        self._delete_leaf(x)
        # 父节点变为叶节点时也可驱逐
        if x.parent.lock_ref == 0:
            heapq.heappush(heap, (priority, x.parent))
驱逐策略对比
策略优先级计算适用场景
LRUlast_access_time 越早 → 越先驱逐默认，通用场景
LFUhit_count 越少 → 越先驱逐长期服务，热点前缀保护
FIFOcreation_time 越早 → 越先驱逐公平性场景
Prioritynode.priority 越低 → 越先驱逐多租户，支持优先级差异
